# Development workflow: OpenCode with DeepSeek, Matt Pocock skills, AGENTS.md

Day-to-day implementation is done with OpenCode on DeepSeek, using the Matt Pocock skills checked into the repo, with AGENTS.md as the single source of agent instructions (CLAUDE.md and other agent files only point to it). Claude Code plans critical phases and reviews pull requests. Gentle-AI SDD/ODD flows are not used in this repo, and their artifacts (`openspec/`, `odd/`, feature documents) are not created, so there is one workflow and one place for specs.
